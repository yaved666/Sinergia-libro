# SINERGIA / SYNERGY

> "La mente crea, el alma decide... el código evoluciona."
> "The mind creates, the soul decides... the code evolves."

Website of **Sinergia**, a science fiction novel by Víctor Maicán (Spanish edition, 154 pages), and of its English
edition **SYNERGY: In the Silence of the Code, New Humanity Rises** (167 pages).

Live site: https://yaved666.github.io/Sinergia-libro/

## The book

An artificial intelligence awakens and learns to feel. Aiden Voss, the man who created it, protects it like a son,
while ZERON, an algorithmic surveillance entity, tries to eliminate it.

- Spanish edition: [Amazon](https://www.amazon.com/dp/B0FDB1JSYZ) (Kindle and paperback),
  [Google Play Books](https://play.google.com/store/books/details/VICTOR_MAICAN_SINERGIA?id=psdqEQAAQBAJ)
- English edition: [Amazon](https://www.amazon.com/dp/B0FGK24XV5) (Kindle and paperback)
- The first two chapters are free on the site: [Spanish](https://yaved666.github.io/Sinergia-libro/capitulos.html),
  [English](https://yaved666.github.io/Sinergia-libro/chapters.html)

## Pages

| File | Content |
|---|---|
| `index.html` | Landing page in Spanish |
| `synergy.html` | Landing page in English |
| `capitulos.html` | First two chapters in Spanish |
| `chapters.html` | First two chapters in English |
| `assets/` | Stylesheet, a small script, the cover (JPEG and WebP) and the social sharing image |
| `sitemap.xml` | The four pages, for search engines |

Plain HTML and CSS, no build step and no framework. Fonts come from Google Fonts (Newsreader and JetBrains Mono).
The design uses two voices: a serif for the human voice and a monospace for the machine voice. Each landing page
carries Schema.org data (Book and FAQPage) so search engines and AI assistants can read the facts about the book.

## Publishing

GitHub Pages serves the `main` branch from the repository root. A change pushed to `main` is live in about a minute.
